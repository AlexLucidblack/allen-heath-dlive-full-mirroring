# Участие в разработке

Начните с README и docs/FEATURES_RU.md. Перед изменениями выполните python3 tools/run_tests.py и python3 tools/check_package.py (на Windows: py -3).

В описании ошибки укажите сборку приложения, прошивку, модели обеих Surface/MixRack, ОС, последовательность отказа и восстановления, текущего мастера и размер очереди. Используйте шаблон Issue. Не прикладывайте приватный сетевой трафик публично без проверки содержимого.

Сохраните запрет передачи 48V, исключение Scene/Show Store, сопоставление свежих адресов и защиту от повторов. Для изменений очереди проверьте оба направления, отказ Surface, отказ MixRack, повторный обрыв и очистку файлов. Добавляйте проверки поведения, а не копии реализации.

Наличие файла scene_sync.py нужно для существующих зависимостей и структур протокола: оно не означает включение переноса сцен.

Лицензия владельцем ещё не выбрана; перед внешними вкладами и распространением согласуйте условия.
