# Сообщения о проблемах

Интерфейс HTTP слушает 127.0.0.1; команды изменения требуют токен текущего процесса. Программа предназначена для доверенной локальной сети управления оборудованием. Она не предоставляет облачный доступ, TLS, учётные записи или удалённую аутентификацию устройств.

Не публикуйте необработанные диагностические JSON/JSONL и PCAP: они могут содержать IP-адреса, пути, названия и параметры шоу. Трафик не нужен для обычной установки. Логи автоматически удаляются; для расследования скачайте их до очистки и до «Отключить оба».

Канал приватных сообщений владельца в пакете не задан. После создания репозитория владелец должен указать его здесь или включить private vulnerability reporting. Не размещайте детали потенциальной уязвимости в публичном Issue до согласования канала.
