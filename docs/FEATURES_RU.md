# Полный функционал и границы

Сборка 0.6.6. Одна и та же реализация используется в Windows и macOS. В таблице «реализовано» описывает поведение кода; это не утверждение, что проверена каждая комбинация оборудования.

## Подключение и управление

Интерфейс локализован на русский и английский. Выбор в шапке сохраняется в браузере; переключение во время работы не меняет сетевую конфигурацию и очередь. Технические коды диагностики сохраняются.

| Функция | Реализация | Ограничение |
|---|---|---|
| Независимость от Director | Прямые AH-Net TCP/UDP-сессии | Нужен работающий компьютер Mirror |
| Два MixRack | Отдельная регистрация, UDP и TCP | Исходная конфигурация не копируется целиком |
| Две Surface | Отдельные сессии op=1, обнаружение имён | Surface должна быть доступна по IP |
| Два локальных IP | Привязка сокетов к адресам ОС | Адреса заранее назначаются в ОС |
| Модели Surface | S7000/S5000/S3000/C3500/C2500/C1500/CTi1500 | Все модели отдельно на железе не проверялись |
| Модели MixRack | DM32/48/64 и CDM32/48/64 | Возможность выбрать модель не гарантирует одинаковую конфигурацию I/O |
| Направление | Начальное 1 → 2 или 2 → 1 | Одновременного пользовательского 1 ⇄ 2 нет |
| Настройки | connection.json после подключения | Конфигурация не содержит всей текущей микшерной сцены |
| Веб-интерфейс | Локальный HTTP 127.0.0.1, порт 8780 по умолчанию | Не удалённая панель через Интернет |

## Передача изменений

| Группа | Что делает приложение |
|---|---|
| Фейдеры/Mute | Передаёт распознанные записи состояния; антиэхо и сокращение повторов при обрыве |
| DSP и канальные группы | Передаёт полученные свойства подписанных объектов: в каталоге есть PEQ, фильтры, Gate/SCF, Compressor, Dynamics Unit, delay, digital attenuator, preamp model и insert |
| Маршрутизация/посылы | Передаёт изменения внутри подписанных mixer/source-select объектов по имеющимся шаблонам |
| FX | Передаёт свойства подписанных FX Manager; поддержка не означает перенос локальных библиотек/шоу |
| Имена/цвета | Подписанные объекты имени/цвета входят в каталог |
| Global Tempo/Tap | FX Global Tap Tempo, период в мс; отдельная регистрация и опрос мастера примерно каждые 250 мс |
| Strip Assign | Изменения позиции в шести слоях, геометрия трёх банков читается с каждой Surface |
| Прочие свойства Surface | Полученные свойства базовых подписанных объектов вне локального хранения и фильтра 48V |
| Дополнительные объекты Surface | Surface Soft Controls, South Processing Config Manager, Soft Rotaries Control Manager — только наблюдение, без записи |
| Известные уведомления | Преобразуются в команды записи с новым адресом назначения |
| Неизвестные свойства известных объектов | Передаются через сопоставление имени и нового адреса |
| Полностью непрозрачные данные | Текущие правила передачи исходных байтов; после смены сессии могут блокировать восстановление |

Каталог содержит фиксированные 2857 объектов, а не 2857 независимо проверенных функций. Часть объектов может отсутствовать на конкретной системе. Возможность подписаться не доказывает корректную семантику записи каждого неизвестного свойства. На другой прошивке нужен отдельный тест.

## Защита от циклов и локальные данные

| Поведение | Статус |
|---|---|
| Подавление обратного эха | Включено |
| Подавление распознанных дубликатов | Включено по существующим правилам |
| Свежие адреса при переподключении | Обнаруживаются по имени; ID из захвата не фиксируются |
| Phantom 48V | Передача запрещена в обычном потоке и очереди |
| Heartbeat, регистрация и служебные ответы | Остаются локальными |
| Известные измерения и системный журнал | Не зеркалируются |
| Metering Sources | Поток уровней не запрашивается как часть зеркала |
| Surface Scene Manager / Scene Manager Intermediate / Library File Manager | Локальное хранение, не перенос Store |
| Сохранение сцен и Show | Отключено; разработка прекращена |

## Автоматический резерв

| Функция | Поведение |
|---|---|
| Контроль четырёх устройств | TCP/UDP-состояние, свежесть сессии, подписки, геометрия; ping как доп. информация |
| Интервал монитора | Около 250 мс; ICMP-задачи запускаются примерно раз в секунду |
| Порог свежести | Порядка 4 с в проверках сессий; это не гарантированное время переключения |
| Повтор соединения | Попытки примерно раз в 3 с, с учётом длительности подключения |
| Отказ ведущей системы | Исправная полностью готовая сторона становится мастером |
| Возврат | Автоподключение и передача накопленных действий |
| Отказ только Surface/Rack | Здоровая соседняя сессия сохраняется |
| Приоритетная подписка | Сначала объекты, которые нужны очереди |
| Частичная готовность назначения | Известные записи могут начаться до завершения полного каталога |
| Возврат старого мастера | Не вызывает обратного захвата управления |
| Потеря обеих систем | Требуется явный новый запуск после восстановления |
| Временный отказ UDP Surface | Повтор UDP без уничтожения живого TCP |

## Очередь

| Параметр | Значение |
|---|---|
| Хранение при обрыве | SQLite с WAL и synchronous=FULL |
| Исправная связь после очистки | Рабочая очередь в памяти |
| Размер | До 250000 незавершённых записей или 128 МиБ |
| Отправка | До 32 команд / 32 КиБ за группу, ограничитель 1000 команд/с |
| Сокращение | Только проверенные абсолютные входные фейдеры/Mute между другими действиями |
| FX/темп/раскладки/неизвестные действия | Не сокращаются этим правилом |
| Порядок | Наблюдаемый порядок получения, без общего счётчика TCP/UDP |
| Подтверждение | Успех сетевой отправки; обычные команды не получают общего readback-подтверждения |
| Непрозрачность/неопределённая отправка | Возможна блокировка восстановления с сохранением данных |
| Перезапуск программы | Продолжение старой очереди не реализовано |

## Логи, диагностика и очистка

В обеих ОС доступны текущие статусы, журнал событий, счётчики, JSON-диагностика и дисковый JSONL-трафик, пока он существует. Поля диагностики подробнее пользовательского экрана: там находятся ping, фазы подписок, ошибки Surface UDP, master/health и log_cleanup.

Очистка закрывает дисковые SQLite и переносит необходимое рабочее состояние в память. Удаляются принадлежащие приложению журналы direct/session/mirror, recovery SQLite/WAL/SHM и служебные резервные JSON из каталога логов. Конфигурация и экспортированные пользователем файлы не удаляются.

Автоочистка требует готовности обеих сторон, отсутствия ошибки и пустоты всех незавершённых очередей текущего процесса. «Отключить оба» принудительно удаляет и незавершённые данные. Корзина не используется.

## Что не входит

Нет передачи аудио, управления резервными аудиовыходами, полного копирования шоу, MIDI/OSC-моста, плагина для Director, облака, мобильного приложения, встроенного редактора всех DSP-параметров, удалённых учётных записей, подписанного установщика или гарантии exactly-once.

Имя Full Mirroring — имя проекта. Фактические ограничения определены реализацией, каталогом и проверками выше.
