# Источники и статус проверки

Документация приложения подготовлена по коду сборки 0.6.6. Функции и лимиты сверены с allen_heath_dlive_full_mirroring.py, redundancy.py, captured_rx.py, surface_link.py, safety_filter.py, recovery_queue.py и JSON-каталогами.

Изображение интерфейса схематически воспроизведено по текущей HTML-разметке до подключения; это не браузерный скриншот. Схема и оформление созданы для проекта. Исходные пользовательские фотографии и PCAP в публикуемый пакет не включены.

Внешние руководства проверены при подготовке 24 октября 2026 года:

- Python на Windows: https://docs.python.org/3/using/windows.html
- Gatekeeper и первый запуск в macOS (дополнено 25 октября 2026 года): https://support.apple.com/ru-ru/102445
- Изменение TCP/IP в macOS: https://support.apple.com/en-in/guide/mac-help/mh14129/mac
- Ручная адресация macOS: https://support.apple.com/en-il/guide/mac-help/mchlp2718/mac
