# Устранение ошибок

Сначала сохраните диагностику, если она нужна: успешная очистка и «Отключить оба» удаляют дисковые журналы. Не удаляйте SQLite вручную.

| Симптом | Возможная причина | Действие |
|---|---|---|
| Нет связи с приложением / Failed to fetch | Python завершился, завис, изменился порт или открыт старый URL | Проверьте окно Python, адрес из терминала и наличие второго экземпляра |
| Не найден Python | Нет runtime или команда не в PATH | Проверьте py -3 --version / python3 --version |
| macOS блокирует неизвестного разработчика | Скачанный файл запуска не подписан Developer ID | Выполните первый запуск и разрешение конкретного файла по инструкции MACOS_RU.md |
| Не найден модуль | Неполная распаковка, удалён служебный .py/JSON | Верните полный комплект в одну папку |
| Can't assign requested address / Errno 49 / WinError 10049 | Локальный IP отсутствует в ОС | Проверьте адаптер, IP, маску, кабель; ввод в Mirror не назначает IP |
| Connection refused при TCP | Неверный адрес/порт или служба ещё не поднялась | Проверьте IP и дождитесь загрузки; тестируйте TCP 51321 |
| Connection refused у UDP Surface | Временный ICMP-отказ при загрузке | В 0.6.4+ UDP повторяется; проверьте udp_transient_errors и живость TCP |
| MixRack подключён, Surface нет | Surface недоступна или не завершены подписки | Проверьте отдельный IP Surface, TCP/UDP и прошивку |
| Ping есть, управления нет | Ping не подтверждает сессию AH-Net | Смотрите health/phase/ошибки в JSON и фактические параметры назначения |
| После возврата старый пульт не мастер | Так работает active/standby | Проверяйте верхний индикатор: мастер остаётся у выжившей системы |
| После возврата очередь не уходит | Не готова Surface/Rack, нет объекта или очередь заблокирована | Скачайте JSON до отключения; проверьте redundancy.error, destination_ready и health |
| Очередь blocked | Непрозрачные адреса, неопределённая отправка или другая ошибка | Сохраните диагностику; не сбрасывайте очередь, если нужны данные |
| Обе системы недоступны | Однозначный автоматический выбор не выполняется | Восстановите оборудование и явно начните новую передачу |
| BPM не совпадает в FX | Эффект не настроен на Global Tap | Сначала сравните общий BPM, затем настройку источника темпа эффекта |
| Не совпал Strip Assign | Разная ширина банков или позиции не помещаются | Проверьте layout_geometry в JSON и фактические слои |
| Нет файлов логов | Автоочистка или исправный режим памяти | Это штатно; JSON-диагностика доступна, трафик после очистки пуст |
| Логи не удаляются | Очередь ещё не завершена/заблокирована или файл занят | Проверьте counts/error/log_cleanup; закрывайте внешние программы просмотра |
| Сцена/Show не появились | Перенос сохранения отключён | Используйте штатные средства dLive, Mirror это не выполняет |
| Изменение 48V не передалось | Намеренная локальность | Настраивайте 48V отдельно на каждой системе |
| Резерв пульта работает, звук не переключился | Аудиотракт отдельный | Реализуйте и проверьте резервирование аудиовыходов отдельно |

## Данные для сообщения об ошибке

Укажите: сборка приложения, прошивка, обе модели Surface/MixRack, ОС и Python; начальное направление; последовательность «отключил → изменил → вернул»; задержки; мастер и очередь после возврата.

В диагностике полезны config, redundancy.phase/master/health/error/counts, surfaces.sides, sides.*.probe, log_cleanup. Полный JSON может содержать пользовательские IP и пути. Перед публичной загрузкой проверьте содержимое. PCAP и JSONL обычно лучше передавать по согласованному каналу, а не публиковать в открытом Issue.
