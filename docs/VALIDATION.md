# Проверка комплекта

- Приложение: 0.6.6; добавлены RU/EN-интерфейс и сохранение языка в браузере. Правила сетевой передачи, очереди, 48V и очистки логов сохранены.
- Дополнительно прошли Node VM-проверки локализации и HTTP/TCP/UDP-сценарий переключения языка во время передачи и смены мастера.
- 110 unittest-проверок прошли локально за 35.6 секунды на loopback-имитаторах.
- Проверены Python AST, JSON-каталоги, импорты и относительные ссылки Markdown.
- Компактный релиз собран из явного списка 20 файлов, включая инструкции RU/EN; проверена целостность ZIP.
- Английская инструкция: 20 страниц A4, полная установка обеих ОС включена в раздел 4; английские схема и обложка, реальные русские подписи интерфейса пояснены переводом.
- YAML workflow и шаблона Issue разбирается без ошибок.
- PDF: 21 страница A4, кириллические шрифты встроены; редакция от 25.10.2026 включает первый запуск macOS через Gatekeeper, изменённые страницы отрендерены и просмотрены.
- Проверены отсутствие выхода текста за поля PDF и отсутствие приватных путей в документации/инструментах.
- В комплект не включены connection.json, логи, SQLite, PCAP, исходные пользовательские фотографии и старые диагностические выгрузки.

Тесты выполнены в среде подготовки. Реальные jobs GitHub Actions, полная матрица ОС и все модели аппаратно на этом этапе не проверялись. Сетевой стенд не заменяет проверку с реальными Surface/MixRack. Внешняя публикация не выполнялась.
